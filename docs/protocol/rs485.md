# RS485 — протокол дополнительных устройств (проектируется)

Статус: **черновик/требования зафиксированы**. Детали кадров/адресов/скоростей — при проработке.

## Назначение
RS485 используется **только ESP32 (мастер)** для некритичных относительно прямой отсечки горелки периферийных устройств (заслонка, насосы тёплых полов, коллекторные модули и т.п.). Nano не использует RS485. Сбой RS485 **не должен** обходить защиту горелки (Nano/safety-gate/независимые контуры).

## Обязательные требования безопасности
- **Изоляция от safety-контура:** защита горелки реализуется Nano + ESP32 основной логикой; RS485 — прикладная шина. Никакие команды RS485 не управляют `*_VALVE_SAFETY`, независимым cutoff `ACT_HEATER_OIL`, safety-логикой Nano.
- **Fail-safe default на slave-устройствах (обязательно для каждого устройства):** определить безопасное состояние при потере связи с мастером, таймауте команды/опроса, CRC/ошибке кадра, зависании, срабатывании watchdog, потере питания, неопределённости.
  - `ACT_PUMP_FLOOR_1`, `ACT_PUMP_FLOOR_B` (через RS485): по умолчанию **OFF/безопасный останов**, если иное не обосновано гидравликой и согласовано с `safety-reviewer`.
  - `ACT_DAMPER_ACTUATOR` (через RS485): **фиксированная безопасная позиция** (открыта/закрыта/иная) — определить при проектировании дымоудаления; учесть вторичные риски (дымоудаление/перегрев) и независимую остановку горелки Nano.
- **Watchdog/таймаут потери мастера на slave:** обязателен для исполнительных устройств. Таймауты фиксируются численно.
- **Таймауты и повторы на мастере (ESP32):** ограниченные повторы, детект недоступности, перевод прикладного контура в fail-safe.
- **Целостность:** CRC, адресация, защита от ложных/некорректных команд; версия протокола.
- **Развязка/линия:** терминация, защита, при необходимости гальваноразвязка — по схеме (`schematic-engineer`).

## Не определено (требует проработки)
- Формат кадра, таблица адресов/команд, скорости, тайминги.
- Конкретные модели/firmware RS485-устройств и их штатные fail-safe поведения (подтвердить соответствие требованиям).
- Поведение при частичной доступности шины.

## Ревью
Любая реализация протокола/выбор устройств с исполнительными функциями, влияющими на гидравлику/дымоудаление, требует проверки на fail-safe defaults и согласования с `safety-reviewer` (в части отсутствия влияния на защиту горелки и вторичных рисков).
