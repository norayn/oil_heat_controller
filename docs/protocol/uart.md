# Протокол обмена ESP32 <-> Arduino Nano (UART)

Статус: **черновик**. Будет доработан при проектировании (шаг 1-2). `include/common_protocol.h` — отправная точка.

## Параметры связи
- **Интерфейс:** UART
- **ESP32:** `Serial`/`Serial2` (точный выбор определится при пин-мапе)
- **Arduino Nano:** `Serial` (SoftwareSerial не приветствуется для критичного обмена)
- **Скорости:** ESP32 115200, Arduino 9600 (как в текущих заготовках) — при необходимости пересмотреть с обоснованием
- **Гальваноразвязка:** рассматривается (оптопары). Решение зафиксировать при схеме.

## Принципы
- **Простота и предсказуемость** — минимальный протокол, легко валидировать
- **Heartbeat** — обязательный, периодический обмен для детекта потери связи
- **Fail-safe** — при таймауте/ошибке CRC/неверном пакете Safety Unit переходит в безопасное состояние
- **Односторонний приоритет** — Safety Unit может послать аварийное сообщение и заблокировать розжиг/работу
- **Версионирование** — добавить `protoVer` при первой рабочей версии

## Предварительная структура (на основе common_protocol.h)
Текущий `TelemetryPacket`:
```cpp
struct __attribute__((packed)) TelemetryPacket {
    uint8_t startByte = 0xAA;
    float currentTemperature;
    uint8_t systemStatus; 
    uint8_t crc;
};
```

Нужно расширить под двусторонний обмен. Предварительные идеи:
- **Направления:** `ESP32 -> Nano` (запросы/команды), `Nano -> ESP32` (статус/телеметрия/алармы)
- **Тип пакета:** `cmd` / `status` / `alarm` / `heartbeat`
- **Критичные поля:** флаги безопасности, состояние горелки, разрешение розжига, причины блокировки
- **Валидация:** `startByte`, длина, CRC8/CRC16, таймаут приёма

## Требования к реализации
- [ ] **Таймаут приёма** — если пакет не принят за N мс -> ошибка связи
- [ ] **Heartbeat таймаут** — если нет heartbeat > T мс -> **fail-safe** в Safety Unit
- [ ] **CRC** — обязательная проверка целостности
- [ ] **Аварийные пакеты** — высший приоритет, Safety Unit должен их обрабатывать первыми
- [ ] **Синхронизация состояний** — ESP32 всегда должен знать состояние безопасности
- [ ] **Защита от "залипания"** — таймауты на каждый этап обмена
