# BLK-002 — пакет закрытия (DESIGN GATE)

Статус: **OPEN / DRAFT PACKAGE — НЕ закрывает BLK-002**.  
Требуемые approval gates: `schematic-engineer` + `safety-reviewer` APPROVE схемы/топологии; `safety-reviewer` ACK остаточного риска залипания (draft).  
Связь: `docs/architecture/blockers.md` → BLK-002 (CRITICAL), SR-B4, SR-B18, SR-B14/B15/SR-B12/S-42.

## Область
Общий Nano-управляемый силовой cutoff/block-stop (контактор/силовое реле, **не самозамыкающийся, без самоподхвата**, управление **только Nano**, **без шунтирования/дублирующих путей**) для группы:
- `ACT_HEATER_OIL` (ТЭН подогрева, 220В)
- `ACT_PUMP_OIL_TRANSFER` (насос подкачки, 220В)
- `ACT_IGNITION_UNIT` (блок розжига, 220В)

`ACT_FAN_BLOWER` — **в обход** (BLK-001 ACCEPTED DESIGN). Nano safety-gates топлива/воздуха (`*_VALVE_SAFETY`, NC, только Nano) и `SEN_AIR_PRESSURE` (прямой Nano) — независимые инварианты.

## Зафиксированные решения (draft/intended)
- Устройство: мощное силовое реле/контактор, **не самозамыкающееся**.
- Управление: **только Nano**; **нет самоподхвата и шунтирования** (Main Unit/KC868/SSR/альтернативные пути).
- В аварии/неопределённости группа обесточивается разом.
- **Draft (ACK required):** остаточный риск залипания/сварки/несостоявшейся отсечки принят как остаточный; отдельная аппаратная weld-mitigation в текущем объёме не требуется. Риск **не устранён физически**.

## Обязательные компенсирующие меры (не снимать)
- Nano safety-gates NC (только Nano) + `SEN_AIR_PRESSURE` предотвращают опасную подачу топлива/воздуха при сварке/залипании общего контакта.
- SR-B4: SSR/драйвер **не** аварийное отключение; Nano cutoff **последовательно с ТЭН**; **термовыключатель/«теплушка» на корпусе нагреваемого бака** + термопредохранитель/предохранители. При сварке контакта неконтролируемый нагрев ограничивается только подтверждённой термозащитой.
- Feedback **fail-safe полярности** (`UNKNOWN/FAULT` != «отсечено подтверждённо»).
- **Latch / запрет повторной подачи / запрет опасного рестарта** при неподтверждённой или неуспешной отсечке.
- Последствия «нагрузка остаётся запитанной при закрытых safety-gates» (подкачка, розжиг, ТЭН) — описаны и приняты в FMEA/safety rationale.

## 1) Топология (schematic required)
- [ ] Силовая схема группы: источник питания, защита ветвей (автоматы/предохранители — номиналы отдельный шаг), Nano cutoff контакт(ы), разводка на `ACT_HEATER_OIL`, `ACT_PUMP_OIL_TRANSFER`, `ACT_IGNITION_UNIT`.
- [ ] **Нет самоподхвата** катушки/привода; нет удерживающих контактов, создающих bypass.
- [ ] **Нет шунтирования**: Main Unit/KC868 relay/SSR/проводка не могут подать питание в обход Nano cutoff.
- [ ] `ACT_HEATER_OIL`: внешний SSR/драйвер (прикладное) + Nano cutoff **последовательно с ТЭН**. Показать фазировку/полюса/защитные элементы.
- [ ] `ACT_PUMP_OIL_TRANSFER`: Nano cutoff обеспечивает hardware block/stop fail-safe OFF.
- [ ] `ACT_IGNITION_UNIT`: обесточивание в составе группы; учесть ЭМС/наводки ВВ розжига.
- [ ] `ACT_FAN_BLOWER` подтверждённо в обход (BLK-001).

## 2) SR-B4 — цепь ТЭН (heater, critical)
- [ ] SSR/драйвер **не** используется как аварийное отключение.
- [ ] Nano cutoff последовательно с ТЭН.
- [ ] **Термовыключатель/«теплушка» на корпусе нагреваемого бака**: место установки, тепловая связь, уставка/гистерезис, номиналы по току/напряжению/среде, fail-safe направление (размыкание при перегреве), проводка в защитной цепи.
- [ ] **Тип сброса теплушки (ручной / самовозврат)** — явно зафиксирован в схеме; совместимость с latch/no auto-resume; **`safety-reviewer` ACK**.
- [ ] Термопредохранитель/предохранители по схеме.
- [ ] Анализ: сварка Nano cutoff / залипание SSR / отказ управления => нагрев ограничивается только подтверждённой термозащитой; нет обхода теплушки/термопредохранителя.

## 3) SR-B18 — подкачка масла
- [ ] Nano cutoff даёт hardware block/stop, fail-safe OFF.
- [ ] Нет обхода прикладным реле KC868/FPC/проводкой.
- [ ] При запитанном насосе (weld residual risk) safety-gates/уровни/Nano-политика не допускают опасную подачу топлива в горелку; FMEA фиксирует остаточный риск и эксплуатационные последствия.

## 4) Fail-safe управление Nano (SR-B14/B15/SR-B12/S-42)
- [ ] Драйвер катушки/управления cutoff: reset, brownout, Hi-Z, WDT reset, bootloader, потеря питания Nano/драйвера => **размыкание/de-energize**.
- [ ] Определённые уровни (pull-up/pull-down), active polarity, защита от дребезга/ложного включения.
- [ ] Nano **никогда** не режет собственное питание (SR-B6 контекст).
- [ ] Таблица состояний: normal ON/OFF, Nano fault, Nano power loss, driver fault, feedback fault.

## 5) Feedback (fail-safe полярность)
- [ ] Сигнал(ы) feedback на Nano: состояние `OFF_CONFIRMED` / `ON_CONFIRMED` / `UNKNOWN` / `FAULT` (или эквивалент) с обоснованием.
- [ ] **Обрыв/КЗ/потеря питания/недостоверность feedback = `UNKNOWN/FAULT`, не `OFF_CONFIRMED`**.
- [ ] Физическая реализация (aux contact, mirror contact, voltage sense и т.п.) — по схеме; не создаёт шунтирования силовой цепи.
- [ ] Поведение Nano: `UNKNOWN/FAULT` при требуемой отсечке => latch, запрет повторной подачи/опасного рестарта, safe state.

## 6) FMEA / residual risk (weld draft)
- [ ] Режимы отказа: залипание/сварка контакта, неполное размыкание, залипание драйвера, ложный feedback, потеря feedback, самоподхват (должен быть исключён схемой), шунтирование (должно быть исключено).
- [ ] Для каждого: эффект, обнаружение, компенсация, остаточный риск.
- [ ] Явная запись: **residual weld/non-opening risk accepted as draft — `safety-reviewer` ACK required**. Физический риск не устранён.
- [ ] Подтверждено: при сварке контакта safety-gates не дают опасную подачу топлива/воздуха; ТЭН ограничен теплушкой/термопредохранителями; подкачка/розжиг — последствия оценены.

## 7) Нагрузки / среда (номиналы — отдельный шаг, но характеристики обязательны)
- [ ] AC-категория/тип контакта подходит для резистивной (ТЭН), двигательной (подкачка) и специфической (розжиг) нагрузки.
- [ ] Inrush/пусковые токи, ЭМС/наводки ВВ розжига, подавление транзиентов согласованы.
- [ ] 220В монтаж, изоляция, clearance/creepage, DIN-вне отсека котла, защита цепей (S-48/BLK-009 контекст) — `schematic-engineer`.
- [ ] Конкретные номиналы/модели — отдельный шаг; выбор не снимает gates.

## 8) Evidence / тесты (до эксплуатации)
- [ ] Power-on/reset/brownout/Hi-Z/WDT: cutoff разомкнут (стенд/осциллограф/логика).
- [ ] Команда Nano OFF при нормальном питании: все три нагрузки обесточены.
- [ ] Feedback fail-safe: обрыв/неисправность feedback => `UNKNOWN/FAULT`, не `OFF_CONFIRMED`.
- [ ] Weld/stuck simulation (если практически применимо) или анализ/обоснование обнаружения; подтверждение поведения latch.
- [ ] SR-B4: проверка цепи ТЭН, размещения/срабатывания теплушки (по методике), отсутствие обхода.
- [ ] SR-B18: подтверждение fail-safe OFF подкачки.
- [ ] `safety-reviewer` evidence review.

## Критерий закрытия BLK-002
BLK-002 можно перевести в **CLOSED/APPROVED** только при наличии:
1. Утверждённой схемы (пп. 1–5, 7) — `schematic-engineer` + `safety-reviewer` APPROVE.
2. FMEA/residual risk с явным **`safety-reviewer` ACK** draft принятия риска залипания (п. 6).
3. Подтверждённых компенсирующих мер (safety-gates/`SEN_AIR_PRESSURE`/SR-B4 тепловая цепь/feedback/latch/no restart).
4. Evidence/тестов (п. 8) до опытной эксплуатации.

До выполнения всех пунктов статус BLK-002 остаётся **DESIGN GATE / не закрыт**.
