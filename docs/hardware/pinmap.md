## Чек-лист при заполнении
- [ ] Все пины из плана назначены и не конфликтуют
- [ ] UART между модулями выделен отдельно
- [ ] Критичные входы (пламя, давление воздуха, поплавки) — продуманы
- [ ] Реле 220В через развязку
- [ ] Достаточно пинов под все актуаторы модуля
- [ ] Учтены особенности Nano/ESP32 (питание, уровни)
- [ ] Зафиксировано обоснование назначения
