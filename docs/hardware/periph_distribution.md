# Распределение периферии по модулям (Main Unit KC868-A6 / Safety Unit Arduino Nano)

Статус: **актуализировано**. Main Unit — **KC868-A6 (ESP32-WROOM-32)**, принят условно/safety-gated (`docs/hardware/kc868-a6_analysis.md` §6). Safety Unit — **Arduino Nano**, не заменяется.
Источник правды по перечню периферии: `rnd/peripherals.md`.

> **Границы документа:** кто владеет каждой периферией и какой независимый backup есть у Nano. Физические линии/пины — `docs/hardware/pinmap.md`; бюджет и дефицит линий A6 — `docs/hardware/kc868-a6_connection_plan.md`; роли и принципы — `docs/architecture/modules.md`; статусы и gates — `docs/architecture/blockers.md`.

## Принципы распределения
- **Безопасность превыше всего.** Критичные датчики и контуры защиты — прямые на Nano.
- **Два уровня.** Main Unit — прикладное управление. Nano — супервизор с независимыми аппаратными контурами и safety-gate. Onboard реле/опто-входы KC868 (PCF8574/I2C) **не fail-safe** и **не safety path**.
- **Последовательные клапаны (NC).** На масло и воздух — по 2 NC-клапана. `*_VALVE_MAIN` — рабочие (Main Unit), `*_VALVE_SAFETY` — safety-gate (только Nano). Main Unit управляет только 2 из 4.
- **Fail-safe.** При потере связи/аварии/неопределённости приоритет за Nano.
- **RS485-актуаторы (S-49).** `ACT_DAMPER_ACTUATOR`, `ACT_PUMP_FLOOR_1/B` — только через RS485 slave (ESP32 мастер), прямых GPIO нет; non-safety.
- **Не гадать.** Схема/пин-мап/grounding — шаг 3 с `schematic-engineer` + `safety-reviewer`.

Финальная тепловая защита — термовыключатель/«теплушка» на корпусе бака + термопредохранитель/предохранители. BLK-002. |

| `ACT_PUMP_BOILER` | Циркуляционный насос котла | 220В | Прикладное управление (реле KC868) | Дублированное включение напрямую возможно, но **не по умолчанию** (схема, автомат); BLK-007 | Оставание ON в аварии — допустимо по решению пользователя (SR-B17). Приоритеты/обратное питание — схема. |
| `ACT_DAMPER_ACTUATOR` | Привод дымовой заслонки (перспектива) | 220В через RS485 | Команды через RS485 (мастер) | Не управляет | RS485 slave; при потере связи — безопасная позиция. Non-safety, S-49. |
| `ACT_PUMP_FLOOR_1` | Насос тёплого пола 1-го этажа (перспектива) | 220В через RS485 | Команды через RS485 (мастер) | Не управляет | RS485 slave; fail-safe default OFF + watchdog. Non-safety. |
| `ACT_PUMP_FLOOR_B` | Насос тёплого пола подвала (перспектива) | 220В через RS485 | Команды через RS485 (мастер) | Не управляет | Аналогично `ACT_PUMP_FLOOR_1`. |

> **Дозирующий насос (PROPOSED, кода в `rnd/peripherals.md` нет).** Возможное дополнение/замена `ACT_PUMP_OIL_TRANSFER`: STEP/DIR — только direct GPIO Main Unit (не PCF8574/I2C), силовое питание драйвера — через Nano cutoff. Требует расширения BLK-002, FMEA и `safety-reviewer`. Детали — `docs/hardware/kc868-a6_connection_plan.md` §3.5.

## 3. Связь, сервисные функции, хранение

| Элемент | Main Unit (KC868) | Arduino Nano (Safety) | Обоснование |
|---|---|---|---|
| **Связь Main Unit ↔ Nano** | Участник (heartbeat/телеметрия/команды); USB-C/CH340 — debug | Участник + супервизор (heartbeat, permit/alarm, fail-safe) | Dedicated point-to-point UART. GPIO/уровни/grounding — шаг 3. |
| **RS485 (non-safety)** | Только ESP32 (мастер) | Не используется | `ACT_DAMPER_ACTUATOR`, `ACT_PUMP_FLOOR_1/B`. Сбой RS485 не обходит защиту горелки. |
| **Детект пропадания сети 220В** | Main Unit | Не зависит для базовой отсечки | Антидребезг/гистерезис, UPS-политика; Nano информируется по UART. |
| **Supervised power-cycle Main Unit** | — | **Nano (SR-B6, last resort)** | Power-cycle 12В KC868: supervised, current-limited, 3-state feedback, latch. Nano не отсекает своё питание. |
| **Коды ошибок / NVM** | Оба модуля | Оба модуля | Severity + сохранение кода при аварии. Определения — `include/common_protocol.h` с `safety-reviewer`. |

## 4. Инварианты (не ослаблять)

- `ACT_OIL_VALVE_SAFETY`, `ACT_AIR_VALVE_SAFETY` — **только Nano**, NC, независимые контуры.
- `SEN_AIR_PRESSURE`, `SEN_OIL_TEMP_SAFETY`, `SEN_FLOAT_MIN/MAX` — **только прямые входы Nano** (не PCF8574/опто/RS485).
- `ACT_HEATER_OIL`, `ACT_PUMP_OIL_TRANSFER`, `ACT_IGNITION_UNIT` — в группе **общего Nano-контактора** (не самозамыкающегося, только Nano, без шунтирования).
- `SEN_FLAME` — baseline SR-B13/S-47; отклонение BLK-005 не реализуется до APPROVE.
- `SEN_THERMOCOUPLE_K` — технологический Main Unit, не Nano-interlock (BLK-003, ACK).
- Nano сохраняет финальное право блокировки; PCF8574/I2C — не safety path.
