# Распределение периферии по модулям (Main Unit KC868-A6v3 / Safety Unit Nano)

Статус: **актуализирован** под архитектурное решение Main Unit = **KC868-A6v3 (ESP32-S3)**, safety-gated по `docs/hardware/kc868-a6v3_analysis.md` §7/§14. Сохранены safety-gate клапаны, независимые Nano cutoffs/block-stop, RS485-актуаторы (non-safety), FPC опционально.  
Источник правды: `rnd/peripherals.md`. Основано на `docs/architecture/modules.md`, `docs/hardware/io_analysis.md`, `docs/safety/checklist.md`.

## Принципы распределения
- **Безопасность превыше всего.** Критичные датчики/контуры защиты — с приоритетом на независимость Nano.
- **Два уровня защиты.** Main Unit (KC868) — прикладное управление; Nano — супервизор с независимыми аппаратными контурами и safety-gate. KC868 onboard реле/опто-входы (PCF8574/I2C) **не fail-safe** и **не safety actuation path**; основные актуаторы — **внешние** модули + Nano cutoffs.
- **Последовательные клапаны (NC).** На масло и воздух — по 2 NC последовательно. **`*_VALVE_MAIN` — рабочие (Main Unit)**, **`*_VALVE_SAFETY` — safety-gate (только Nano)**. Nano открывает при безопасных условиях; при аварии/потере связи/неопределённости закрывает через независимые контуры. Main Unit управляет **только 2 из 4** клапанов.
- **Fail-safe.** При потере связи/аварии/неопределённости приоритет за Nano.
- **RS485-актуаторы (S-49).** `ACT_DAMPER_ACTUATOR`, `ACT_PUMP_FLOOR_1/B` — через RS485 slave (ESP32-S3 мастер). Прямых GPIO нет. DMX512/Modbus — раздельные сегменты; runtime `DE/RE`/timeouts/abort limits; non-safety.
- **Решения не гадать.** Схема/пин-мап/grounding — шаг 3 с `schematic-engineer` + `safety-reviewer`.

## 2. Датчики и измерительные приборы

### 2.1. Безопасность и контроль горения (горелка)
| Код | Наименование | Тип/интерфейс | ESP32 | Arduino Nano (Safety) | Обоснование |
|---|---|---|---|---|---|
| `SEN_FLAME` | Датчик наличия пламени | Фоторезистор -> аналоговый вход KC868 (PROPOSED, BLK-005) | **Ведущий контроль FSM (Main Unit)** | **Наблюдение через heartbeat/`flameStatus`/FSM status; прямого входа нет** | Решение пользователя: фоторезистор на **аналоговый вход KC868**, экранированный кабель + практические тесты наводок при розжиге; при недостаточности — **опторазвязка/изолированный формирователь (digital/Schmitt) на direct ESP32-S3 GPIO**. **Отклонение от SR-B13/S-47** (ADC-raw ранее запрещён) — **NOT VALIDATED**. Обязательно: fail-safe пороги/гистерезис/debounce/диагностика, обрыв/КЗ/потеря питания/saturated/stuck = «нет пламени», PASS/FAIL ЭМС-тесты при розжиге, `safety-reviewer`+`schematic-engineer` APPROVE. |
| `SEN_AIR_PRESSURE` | Датчик давления сжатого воздуха (пороговый) | Пороговый (вкл/выкл) | **Использует по данным/наблюдение** | **Основной контроль для независимой защиты** | **Однозначно в ведении модуля безопасности Nano.** Критичен для независимых аварийных отсечек. |
| `SEN_THERMOCOUPLE_K` | Термопара K-типа температуры выхлопных газов + модуль MAX6675 | Термопара + MAX6675 (SPI) | **Подключение к Main Unit (KC868), технологическая обратная связь горения** | **Не зона контроля Nano Safety (BLK-003, ACCEPTED RISK, ACK req.)** | Решение пользователя: температура выхлопа — **не зона контроля модуля безопасности**; задача — обратная связь по процессу горения. Nano независимого hardware-триггера перегрева выхлопа не имеет. Main Unit при недостоверности/timeout/fault => безопасный прикладный режим по FSM. Требуется `safety-reviewer` ACK границы ответственности; placement/диагностика MAX6675 — по схеме. |
| `SEN_OIL_TEMP_SAFETY` | Датчик температуры масла в бачке нагрева (дублирующий, для аварийной отсечки) | DS18B20 | **Использует** | **Основной контроль для независимой защиты** | Выделенный для аварийной отсечки. Ведущее назначение — Nano для независимого отключения `ACT_HEATER_OIL` и других защитных действий. |

|---|---|---|---|
| **Связь Main Unit<->Nano** | **Участник (heartbeat/телеметрия/команды), native USB debug** | **Участник + супервизор (heartbeat, permit/alarm, fail-safe)** | **Dedicated point-to-point UART** (рекомендация). ## Опциональный вариант: FPC (контур подготовки топлива)

Статус: **не принят**, анализ зафиксирован в `docs/architecture/modules.md`. При рассмотрении варианта FPC:
- `SEN_OIL_TEMP_SAFETY`, `SEN_FLOAT_MIN/MAX` остаются **прямо подключёнными к Nano** (основной контроль безопасности). Перенос только на FPC запрещён.
- `ACT_HEATER_OIL`: прикладное управление (ПИД) может быть у FPC/Main Unit, но Nano обязан иметь **независимый series cutoff в силовой цепи последовательно с ТЭН** (SR-B4, обход невозможен) + термозащита по схеме.
- `ACT_PUMP_OIL_TRANSFER`: прикладная логика может быть у FPC/Main Unit, но Nano обязан иметь **независимый аппаратный hardware block/stop в силовой цепи насоса, fail-safe default OFF** (SR-B18). Иные варианты — только после анализа отказов/схемы и отдельного `APPROVE` `safety-reviewer`.
- Связь с FPC: при внедрении предпочтителен **гибрид** (аппаратный safety-gate от Nano + RS485 телеметрия/команды). Безопасность не опирается только на FPC/RS485. Fail-safe при потере связи/неопределённости.
- Любая реализация — только после схемы `schematic-engineer` и ревью `safety-reviewer`.

## Краткие выводы по ключевым требованиям
- **Клапаны масло/воздух (по 2 последовательно):** `ACT_*_VALVE_MAIN` — рабочие, **Main Unit**; `ACT_*_VALVE_SAFETY` — safety-gate, **Nano** (физическое дублирование). Main Unit управляет только 2 из 4 клапанов. ✓
- **Давление воздуха (`SEN_AIR_PRESSURE`)** — Nano. ✓
- **Пламя (`SEN_FLAME`)** — Main Unit, **PROPOSED/NOT VALIDATED (BLK-005)**: фоторезистор -> аналоговый вход KC868 + экранирование + ЭМС-тесты при розжиге; fallback — опто/изолированный формирователь (digital/Schmitt) на direct ESP32-S3 GPIO. Отклонение от SR-B13/S-47; `safety-reviewer`+`schematic-engineer` APPROVE до реализации. ✓(условно)
- **Температура выхлопа (`SEN_THERMOCOUPLE_K`)** — Main Unit, **технологическая обратная связь горения** (BLK-003, ACCEPTED RISK, ACK req.). Не зона контроля Nano Safety; Nano не имеет независимого триггера перегрева выхлопа. ✓(граница ответственности)
- **ТЭН, насос подкачки, розжиг** — в группе **общего Nano-контактора** (SR-B4/SR-B18 цели) + термозащита ТЭН. BLK-002 design gate (feedback/weld/fail-safe outputs) открыт. ✓(схема pending)
- **Вентилятор наддува (`ACT_FAN_BLOWER`)** — KC868 relay; Nano может **обесточить всю плату KC868** (coarse, SR-B6, аварийно) + автомат; per-circuit cutoff нет. Штатная продувка — при живой KC868/FSM; аварийный board-off несовместим с управляемой продувкой. `SEN_AIR_PRESSURE` Nano + safety-gates + обесточивание ТЭН/подкачки/розжига контактором обязательны. BLK-001 открыт. ✓(с условиями)
- **Насос котла (`ACT_PUMP_BOILER`)** — KC868 relay; возможно дублированное включение Nano (автомат). Оставание ON в аварии — не проблема (решение пользователя). BLK-007 schematic open. ✓
- **Заслонка/насосы тёплых полов** — RS485 slave, S-49. ✓
- **RS485** — только Main Unit мастер, non-safety. ✓
- **Детект пропадания питания** — Main Unit; Nano не зависит для базовой отсечки. ✓
- **Коды ошибок, хранение в памяти** — оба модуля. ✓
- **KC868 onboard PCF8574 I/O** — **не независимый/fail-safe safety path**. Реле — только прикладное управление при Nano hardware safety-gate/cutoff/block-stop (аппаратный backup, не программный). ✓
- **Блокеры/статусы:** `docs/architecture/blockers.md`. ✓
