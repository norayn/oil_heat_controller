Мы разрабатываем проект "oil_heat_controller" — безопасный двухмодульный контроллер печи на отрботанном масле.

Проект развернут в VS Code + PlatformIO. Архитектура мультичиповая (Multi-environment) в рамках одного репозитория:
- Модуль 1: Arduino Nano (Atmel AVR, 8-bit, bare-metal) — Ядро безопасности, вспомогательные функции
- Модуль 2: ESP32 (32-bit, FreeRTOS) — Модуль связи, основной контроллер управления системой отопления
- Интерфейс связи: UART (возможно через оптопары) будет ли гальваническая развязка пока вопрос


в минимальном виде это система управления котлом на отработке( из переферии можно примерно понять устройство )
как дополнительные функции управление и контроль системой отопления помещения( в текущем случае двух этажей с теплыми полами )
для каждого теплого пола есть свой модуль подключенный по рс485 управляющий насосом и следящий за температурами( будут добавлены в дальнейшем )
логика работы системы автоматика зажигает печь, та нагревает теплоаккумулятор и выключается, теплые полы опстепенно забирают тепло из теплоаккумулятора, как только контроллер видит что теплоаккумулятор остыл до опредеделнной отмеки он запускает котел и цикл повторяется
благодаря большому количеству датчиков можно отслеживать состояние системы на разных уровнях и более грамотно настраивать
